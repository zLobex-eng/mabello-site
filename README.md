# MABELLO T.I.

**MABELLO T.I.** é o site da minha marca de tecnologia e também o meu portfólio de desenvolvimento web. Ele apresenta serviços, processo de trabalho e contato, e foi feito para clientes e recrutadores. Estou melhorando o projeto aos poucos, como parte do meu aprendizado.

🔗 **Site publicado:** https://mabello-site.vercel.app

📲 **Contato:** preenchendo formulário, para que possa entrar em contato

## Tecnologias

- HTML: estrutura e textos do site
- CSS: visual e responsividade
- JavaScript: interações e animações do site
- Vercel: hospedagem e endereço do site

## Estrutura do projeto

- `index.html`: estrutura e textos
- `styles.css`: visual, responsividade e animações
- `script.js`: interações, scroll, cursor, Canvas e terminal
- `assets/`: logo e imagens

## Como abrir o projeto

1. Neste repositório, clique no botão verde **Code** e depois em **Download ZIP**. Extraia a pasta.
2. Abra o arquivo `index.html` no navegador.

Para estudar o código, abra a pasta inteira no VS Code. Se tiver a extensão Live Server, clique com o botão direito em `index.html` e escolha **Open with Live Server**.
